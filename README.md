# TIC TAC FUTBOL — versión publicable

Aplicación web de asistente de fútbol con IA.

## Funciones
- Chat de IA especializado en fútbol.
- Modo invitado.
- Memoria local de notas.
- Voz mediante el navegador cuando está disponible.
- Pizarra táctica.
- Diseño responsive para celular y PC.
- Preparada para añadir estadísticas, imágenes y un sistema de cuentas.

## Instalación
1. Instala Node.js.
2. Abre una terminal en esta carpeta.
3. Ejecuta `npm install`.
4. Copia `.env.example` como `.env`.
5. Coloca la clave de IA en `OPENAI_API_KEY`.
6. Ejecuta `npm start`.
7. Abre `http://localhost:3000`.

## Seguridad
La clave de IA se mantiene en el servidor. Nunca la pongas en `public/app.js`.
